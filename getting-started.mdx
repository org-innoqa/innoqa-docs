There's no procurement process and no separate onboarding call required to start building — the whole flow lives in one composer.

<Steps>
  <Step title="Describe what you want to build">
    From your [dashboard](https://humainum.com/dashboard), tell the agent your idea in plain language — no spec document required. Start a new website, a new mobile app, renew an existing website, or import something you already have (an existing website, a GitHub repository, a `.zip` file, or an existing mobile app).
  </Step>
  <Step title="The agent plans, builds and checks in">
    It writes real code into a real GitHub repository, and stops for your approval on every important step — nothing ships without you.
  </Step>
  <Step title="Bring in an expert if you need one">
    Stuck on something that needs a human — architecture, design judgment, an unusual integration? Route the task to a verified specialist without leaving your project, priced in the same credits you already use to build. See [Expert network](/expert-network).
  </Step>
  <Step title="Add modules as you need them">
    Once the core build is working, install only the modules your project actually needs — CRM, an omnichannel inbox, a website chatbot, bookings, SEO and more. See [Modules](/modules/overview).
  </Step>
  <Step title="Your project is yours">
    At every stage, your project is a real, portable GitHub repository. Clone it, host it yourself, or hand it to another developer whenever you want — see [Ownership, code & security](/ownership-and-security).
  </Step>
</Steps>
