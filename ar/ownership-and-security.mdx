هذه ليست ميزات قادمة — إنها الطريقة التي يعمل بها كل مشروع Humainum بالفعل، في كل خطة.

<CardGroup cols={3}>
  <Card title="ملكية كاملة 100% للكود" icon="github">
    كل مشروع يحصل على مستودع GitHub حقيقي منذ اليوم الأول. إنه ملكك بالفعل — استنسخه، شغّله على خوادمك الخاصة، أو أشرك فريقًا آخر متى شئت. لا خطوة تصدير، لا قيود.
  </Card>
  <Card title="عزل البيانات لكل مشروع" icon="database">
    يحصل كل مشروع على مخطط PostgreSQL خاص به بصلاحيات وصول محدودة النطاق. الوصول إلى قاعدة البيانات وGitHub ومفاتيح API محمي لكل مشروع على حدة، وليس على مستوى مساحة العمل.
  </Card>
  <Card title="مفاتيحك، بشروطك" icon="key">
    اربط بيانات اعتماد مزود LLM الخاص بك وتحكّم بدقة في النموذج الذي يعمل عليه مشروعك.
  </Card>
</CardGroup>
