The Toolbox is Humainum's connected suite of business modules — install what a project needs, when it needs it, all sharing one Business Profile so every module works from the same facts about your business.

<Note>
  Status reflects where each module is today: **Available** modules are fully shipped, **Beta** modules are live but still maturing, and **Coming soon** modules aren't built yet. Check the [live Toolbox](https://humainum.com/modules) for the current status of any module — this page is a snapshot, not the source of truth.
</Note>

## Core

| Module | Status | What it does |
| --- | --- | --- |
| Business Profile | Available | A shared company profile that keeps your website, content, conversations and campaigns consistent — every connected module reads the same facts before it creates, answers or recommends. |
