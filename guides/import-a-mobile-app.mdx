Already have an iOS or Android app live? Import it and keep building on the real code instead of starting over.

<Steps>
  <Step title="Start an import">
    From the dashboard composer, choose **Import an existing mobile app**.
  </Step>
  <Step title="Tell the agent about your app">
    Platform (iOS or Android), app name, developer name, and the store listing URL if it's already published.
  </Step>
  <Step title="Verify ownership">
    Ownership is verified against the store listing.
  </Step>
  <Step title="Keep building">
    Once verified, describe what you want to change and the agent works on the real code — same as any other Humainum project.
  </Step>
</Steps>

See also: [Native mobile apps](/native-mobile-apps) for how the agent builds for iOS and Android in general.
