Not every decision is something an agent should make alone. When a task needs a person's judgment — architecture, design, an unusual integration — bring in a verified expert.

<Steps>
  <Step title="Open the task from your project">
    From an existing project, choose to route a task to an expert instead of the agent.
  </Step>
  <Step title="Describe what you need">
    The same way you'd describe a task to the agent — what needs to happen and why.
  </Step>
  <Step title="An expert picks it up">
    A verified specialist reviews the project context and works the task inside the same environment your agent is already working in.
  </Step>
  <Step title="It's priced in credits">
    Same credit system you already use to build — no separate invoice or contract.
  </Step>
</Steps>

Want to be the expert instead? See [Expert network](/expert-network) for how to apply.
