---
title: 'Import an existing website'
description: 'Connect a website you already have and keep building on the real code.'
---

You don't need to start over. Connect an existing web project, verify ownership, and continue building on the real code with AI and the team.

<Steps>
  <Step title="Start an import">
    From the dashboard composer, choose **Import an existing website**.
  </Step>
  <Step title="Point at your site">
    Give the AI agent the site's URL (or connect the GitHub repository / upload a `.zip`, whichever matches what you already have).
  </Step>
  <Step title="Verify ownership">
    Prove the site is yours with a DNS TXT record or a `.well-known` file — Humainum shows you exactly which one to add and where.
  </Step>
  <Step title="Keep building">
    Once verified, the project behaves like any other Humainum project — describe changes, and the agent works on the real code.
  </Step>
</Steps>

## Connecting your domain

If you're pointing a custom domain at your project, add an A or CNAME record with your DNS provider (GoDaddy, Natro, Cloudflare, or whichever you use). Remove any existing A/CNAME record with the same name first. DNS changes can take anywhere from a few minutes up to 24 hours to propagate.
